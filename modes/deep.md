# Deep Research Mode

Comprehensive company research and contact discovery.

## Trigger

User says: "research [company]", "tell me about [company]", "find contacts at [company]"

## Research Areas

1. **Company Overview** — What they do, mission, size, funding stage
2. **Engineering Culture** — Tech stack, engineering blog, open source
3. **Recent News** — Funding, launches, layoffs, growth
4. **Interview Process** — Glassdoor reviews, common questions
5. **Contact Discovery** — Hiring managers, recruiters, team leads

## Output Format

```
## Company Research: Stripe

### Overview
- Fintech infrastructure company
- Founded: 2010, San Francisco
- Employees: ~8,000
- Valuation: $65B (2025)
- Funding: Series I

### Engineering Culture
- Tech stack: Ruby, Java, React, Go
- Engineering blog: stripe.com/blog
- Open source: stripe-node, stripe-python
- Values: User-first, move fast, transparent

### Recent News
- Launched Stripe Atlas for international expansion
- Hiring 500+ engineers in 2026
- Expanding to India market

### Interview Process
- 4-5 rounds: Phone screen → Technical → System design → Behavioral → Culture
- Common questions: System design, coding, behavioral
- Average timeline: 2-3 weeks

### Contacts
- Hiring Manager: [Name] — [LinkedIn URL]
- Recruiter: [Name] — [Email]
- Team Page: [URL]

### Recommendation
Strong engineering culture. Apply directly through recruiter if possible.
```

## Tools

- Use `websearch` for company research
- Use `webfetch` for careers page scraping
- Use Glassdoor, LinkedIn, Crunchbase for data

## Rules

- Cite sources for all claims
- Distinguish fact from speculation
- Flag any red flags (layoffs, funding concerns)
- Never fabricate contact information
